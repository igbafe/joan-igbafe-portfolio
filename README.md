# Joan Igbafe - Virtual Legal Assistant

A responsive portfolio website built from the supplied portfolio PDF. It uses plain HTML, CSS and JavaScript and has no build step or runtime dependencies.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The contact form prepares a message in the visitor's email app; it does not submit to a server.

## Content notes

- All 21 visual assets are original images extracted from the supplied PDF: Joan's portrait, 17 legal work-sample screenshots, and three Laboratory Insights newsletter previews.
- Every legal work-sample screenshot has a matching caption and arrow callout. Each screenshot can be opened at full size.
- The interface palette comes from the PDF: cream (#F6E9D8), sand (#EFDAC3), soft cream (#F8EEE2), espresso (#3E2A1F), brown (#775643), clay (#A3836D), and pale tan (#E3C8A9).
- The five Schuyler & Granger LLP case studies are fictional training projects. Every client, matter, name, and case detail shown is invented.
- System serif and sans-serif stacks keep typography available without remote font requests.
